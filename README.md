# Các trang demo

Repo chung chứa mọi trang demo và trang trực quan. Mỗi trang là một thư mục con, mở tại
`https://ntcong248820-gif.github.io/<ten-thu-muc>/`.

- Không tạo repo riêng cho từng demo. Thêm page mới bằng một thư mục mới ở đây.
- Cập nhật page cũ thì giữ tên thư mục để link đã gửi vẫn mở được.
- Mọi trang có `noindex, nofollow`, và `robots.txt` ở gốc chặn toàn bộ.
- Trang luôn công khai với người có link: không đưa số liệu nội bộ, mật khẩu, token, dữ liệu cá nhân.
- `index.html` ở gốc là mục lục, sinh tự động, đừng sửa tay.

Đây là bản demo nội bộ, không phải website chính thức của Thế Giới Di Động.
